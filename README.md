# Data-Analyst-Internship-Task-4
Superstore sales analysis over trend, region, segments, ship mode, etc. analysis

## Objective

The objective of this task was to create an interactive dashboard
that presents sales data through meaningful visualizations and
communicates important business insights.

## Dataset

Superstore sales dataset.

## Tool Used

Power BI Desktop

## Visualizations Created

- Total Sales
- Total Orders
- Total Customers
- Unique Products
- Sales Trend Over Time
- Sales by Category
- Sales by Region
- Sales by Segment
- Sales by Ship Mode
- Top 10 Products
- Top 10 Customers
- Sales by State
- Sales by City
- Sales by Sub-Category
- Regional Sales by Category

## Interactive Filters

- Region
- Category
- Segment
- Ship Mode

## Key Insights

The dashboard was used to identify sales trends,
top-performing categories, regions, products, customers,
and customer segments.

## Conclusion

The dashboard provides an interactive visual summary of
Superstore sales data and demonstrates the use of Power BI
for data visualization and business storytelling.
